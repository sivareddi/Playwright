# VS Code Commands — Mac

## General
| Command | Shortcut |
|---------|----------|
| Command Palette | `Cmd + Shift + P` |
| Quick Open (File) | `Cmd + P` |
| Settings | `Cmd + ,` |
| Keyboard Shortcuts | `Cmd + K Cmd + S` |
| Open Terminal | `` Ctl + ` `` |
| Toggle Sidebar | `Cmd + B` |
| Zen Mode | `Cmd + K Z` |
| Toggle Activity Bar | `Cmd + Shift + B` |

## Editing
| Command | Shortcut |
|---------|----------|
| Comment / Uncomment | `Cmd + /` |
| Block Comment | `Shift + Alt + A` |
| Copy Line | `Cmd + C` (no selection) |
| Cut Line | `Cmd + X` (no selection) |
| Duplicate Line | `Shift + Alt + ↓ / ↑` or `Shift + Cmd + ↓ / ↑` |
| Move Line | `Alt + ↓ / ↑` |
| Delete Line | `Cmd + Shift + K` |
| Find | `Cmd + F` |
| Find & Replace | `Cmd + H` |
| Find in Files | `Cmd + Shift + F` |
| Rename Symbol | `F2` |
| Format Document | `Shift + Alt + F` |
| Indent / Outdent | `Cmd + ]` / `Cmd + [` |
| Jump to Bracket | `Cmd + Shift + \` |
| Go to Line | `Cmd + G` (after `Cmd + P`) |
| Go to Definition | `F12` (or `Cmd + Click`) |
| Peek Definition | `Alt + F12` |
| Select All Occurrences | `Cmd + Shift + L` |
| Add Cursor | `Alt + Click` |
| Multi-cursor (next match) | `Cmd + D` |
| Undo Cursor | `Cmd + U` |
| Toggle Word Wrap | `Alt + Z` |
| Fold / Unfold | `Cmd + Shift + [` / `Cmd + Shift + ]` |
| Fold All | `Cmd + K Cmd + 0` |
| Unfold All | `Cmd + K Cmd + J` |

## Multi-cursor & Selection
| Command | Shortcut |
|---------|----------|
| Select All (Cmd+A) | `Cmd + A` |
| Column Selection | `Shift + Alt + Drag` |
| Expand Selection | `Shift + Alt + →` |
| Shrink Selection | `Shift + Alt + ←` |
| Go to Matching Bracket | `Cmd + Shift + \` |

## Search & Navigation
| Command | Shortcut |
|---------|----------|
| Go to File | `Cmd + P` |
| Go to Symbol in File | `Cmd + Shift + O` |
| Go to Symbol in Workspace | `Cmd + T` |
| Go Back | `Ctrl + -` (or `Cmd + Alt + ←`) |
| Go Forward | `Ctrl + Shift + -` (or `Cmd + Alt + →`) |
| Show All Symbols | `Cmd + T` |
