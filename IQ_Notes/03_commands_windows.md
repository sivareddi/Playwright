# VS Code Commands — Windows

## General
| Command | Shortcut |
|---------|----------|
| Command Palette | `Ctrl + Shift + P` |
| Quick Open (File) | `Ctrl + P` |
| Settings | `Ctrl + ,` |
| Keyboard Shortcuts | `Ctrl + K Ctrl + S` |
| Open Terminal | `` Ctrl + ` `` |
| Toggle Sidebar | `Ctrl + B` |
| Zen Mode | `Ctrl + K Z` |
| Toggle Activity Bar | `Ctrl + Shift + B` |

## Editing
| Command | Shortcut |
|---------|----------|
| Comment / Uncomment | `Ctrl + /` |
| Block Comment | `Shift + Alt + A` |
| Copy Line | `Ctrl + C` (no selection) |
| Cut Line | `Ctrl + X` (no selection) |
| Duplicate Line | `Shift + Alt + ↓ / ↑` |
| Move Line | `Alt + ↓ / ↑` |
| Delete Line | `Ctrl + Shift + K` |
| Find | `Ctrl + F` |
| Find & Replace | `Ctrl + H` |
| Find in Files | `Ctrl + Shift + F` |
| Rename Symbol | `F2` |
| Format Document | `Shift + Alt + F` |
| Indent / Outdent | `Ctrl + ]` / `Ctrl + [` |
| Jump to Bracket | `Ctrl + Shift + \` |
| Go to Line | `Ctrl + G` |
| Go to Definition | `F12` |
| Peek Definition | `Alt + F12` |
| Select All Occurrences | `Ctrl + Shift + L` |
| Add Cursor | `Alt + Click` |
| Multi-cursor (next match) | `Ctrl + D` |
| Undo Cursor | `Ctrl + U` |
| Toggle Word Wrap | `Alt + Z` |
| Fold / Unfold | `Ctrl + Shift + [` / `Ctrl + Shift + ]` |
| Fold All | `Ctrl + K Ctrl + 0` |
| Unfold All | `Ctrl + K Ctrl + J` |
